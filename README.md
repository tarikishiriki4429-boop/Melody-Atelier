# Melody Atelier v0.5.9 — コードタイムライン & 歌声なしの区間

## 新機能

- メロディー編集画面の下に「コードを見ながら編集」を追加。曲全体を拍数に合わせた横スクロールの帯として表示。イントロ・Aメロ・間奏・サビ・アウトロを同一の時間軸上に表示します。
- 色つきのコード帯をタップすると開始拍、長さ、コードの度数、半音変化、種類を編集できます。
- コード帯を左右にドラッグして移動、帯右端のつまみをドラッグして長さ変更。各項目は1/4拍単位のボタンでも調整できます。
- 「＋ イントロ」「＋ 間奏」「＋ アウトロ」で歌詞・音符のないセクションを作成できます。セクション内の最低小節数を変更し、コードだけのフレーズを作曲可能です。
- 「＋ 選択ブロックにコード」で単独コードを追加。「♫ コード進行を選ぶ」で従来の178種類のテンプレート、自作進行、伴奏リズムを引き続き使用できます。
- 「▶ このブロックのコードだけ」では歌メロを鳴らさずコードのみ試聴できます（1回の単独試聴は2分30秒以内）。全曲試聴・WAV・MIDI・Voice Atelier連携ZIPは従来どおり、コードを含む状態で生成可能です。
- 過去のプロジェクトのコード進行は読み込み時に変更せず表示。初めてその帯を選択した時のみ、各コードを編集できるクリップへ変換します。セクションの元の長さは保ちます。
- 編集したコードの区間はプロジェクトJSON・端末内の自動保存で保持します。旧版の保存データ（version:1）との互換性を維持。

## 使い方（例：イントロだけコードを作る）

1. 「＋ イントロ」→ 空のイントロが曲頭に入ります。
2. 「♫ コード進行を選ぶ」でテンプレートを選択し「適用」を押します。または「＋ 選択ブロックにコード」でCなどのコードを追加します。
3. 「コードを見ながら編集」の帯を押して開始位置と長さを指定、必要なら指で帯を移動・伸縮します。
4. 「▶ このブロックのコードだけ」で試聴。間奏・アウトロも同じ手順です。
5. 「プロジェクト保存」で必ずJSONバックアップを取ってください。

## 注意

- GitHub Pagesの同じURLで更新できます。Netlify不要。配布ZIPのファイル一式をアップロードしてください。
- GitHubには作曲データはアップロードされません。ブラウザー内の自動保存は端末やSafariのデータ削除によって消える可能性があります。
- 旧アプリからの更新前に必ず「プロジェクト保存」でJSONをバックアップしてください。
- 連携ZIPのVoice Atelier側の1ブロック最大48小節の制限、最大15分のガイド音声制限は従来どおりです。
- ブラウザーでコードの帯の編集、旧コードの個別変換、イントロのみのWAV・連携ZIPの生成・JSON保存復元を試験しました。iPad Safari実機のタッチ操作は未検証です。

# Melody Atelier v0.5.8

## 今回追加：参考音声ミニプレーヤー

- 画面右下の「🎧 参考音声」を押すと小さな音声プレーヤーが開きます。不要なときは折りたためます。
- iPadのファイルから音声を選択。再生／一時停止／シークバー／音量／再生速度（0.75・1・1.25倍）。
- 読み込める形式はSafariがデコードできる音声（一般的なM4A／MP3／WAVなど）。形式によっては再生できません。
- ファイルはブラウザー内の一時URLとして参照し、サーバーにアップロードしません。アプリの曲データ、WAV、Voice Atelier連携ZIPへ自動混入しません。
- **再読み込み・アプリ終了後には、音声ファイルを再選択してください。** 歌詞・メロディーの保存とは別扱いです。
- 再生音声とアプリのメロディーの位置は**自動同期しません**。録音を参考として耳で比較するための独立再生機能です。
- 長時間ファイルは全体をメモリに読み込まず、Blob URLを通してブラウザーで再生します。
- iPadでHTML音声の個別音量指定が効かない場合は、本体の音量操作で調整してください。

# Melody Atelier v0.5.7

v0.5.6の機能を維持し、次を追加：

- 音階表示の切り替え（C・D・E / ド・レ・ミ〔固定ド〕）。グラフ左側、中央ド、音程選択、選択音情報、調の表示へ即時反映。
- 表示切り替えだけなので、音程・保存済みメロディー・試聴音・MIDI・コードの鳴り方は変更なし。
- 表示の好みをローカル自動保存とプロジェクトJSONに保存。旧プロジェクトは従来のC・D・E表記で読み込み。

以前のv0.5.6で追加されている機能：

- 音符の配置・ドラッグ・微調整を1/4、1/8、1/16拍から選択（既定1/8拍）。半音刻みを維持。
- 「▧ 範囲選択」で矩形を描き複数音を選択、一括ドラッグ／上下左右微調整／まとめて削除。
- コード進行を計178種類に拡張。速い進行、ゆっくり、激情、透明感、半音上昇・下降。
- コードの長さに1/4・3/4・1.5拍を追加。ルートの半音調整（♭、♯）を追加。
- コードの鳴らし方を8種類から選択（1/4拍で刻む・半拍で刻む・分散和音など）。WAV、コード試聴、Voice連携に反映。
- 従来のプロジェクトJSON・自作コードライブラリ形式と互換。

**重要**: 新機能の操作をiPad Safari実機では未確認です。更新前にはプロジェクトJSONとコードライブラリを必ず書き出してください。GitHub Pagesにアップロードする際はZIPを解凍し、中身のファイルを配置します。


## v0.7.0 メロディータブと単音譜面化
- ブロックごとに最大12タブ。編集画面の上部でタップ切り替え、追加・名前変更・複製・削除が可能。
- 選択していないタブの音符は薄く表示され、編集対象にはなりません。全タブ再生と選択タブのみ再生を切り替え可能です。
- 保存JSONに `melodyTabs` と `activeMelodyTab` を追加。旧版の `notes` は主旋律タブとして読み込めます。
- 曲全体の再生、MIDI、Voice連携ZIPは全タブの音符を含みます。
- 「音声を読み込んで譜面化（単音）」は端末内のブラウザで単音音源を簡易解析し、現在のタブに音符を追加します。音源45MB以下、長さ2分以下。音程とリズムは手動修正が必要です。和音、伴奏入り完成曲の分離には非対応です。
- 既存の参考音声再生、コード編集、メロディー単独・コード単独WAV、Voice連携を維持します。

## v0.7.1 編集画面の再生操作
- ピアノロール上部に「曲全体」「このブロック」「選択音から」「停止」を追加。
- コードだけの「曲全体」「このブロック」「選択音から」を追加。コード伴奏トグルOFFでも単独試聴可能。
- コード単独試聴は既存の再生エンジンでWAVを生成し、iPad Safariの標準音声再生を利用。
- 選択音からの再生は、選択した音符の開始拍を基準にする。

## v0.7.2 既存音編集メニューの復帰
- v0.5.7〜v0.7.1の音符インスペクターと長押しメニューを比較して、音程、開始拍、音の長さ、細かな移動、試聴、削除を維持。
- 緑色の「音を詳しく編集」開閉メニューを追加。初期状態は展開済みで、既存の編集欄をそのまま操作可能。
- 音符長押しのメニューに「詳細編集を開く」を追加。タップで緑色の編集欄を開いてスクロール。
- v0.7.1の再生ボタン、メロディータブ、譜面化、連携機能は削除せず維持。

## v0.7.3 クイック再生
ピアノロールの直前に小型の「▶ 選択音から」「■ 停止」を追加。編集欄をスクロールしても使いやすいsticky配置です。既存の曲全体・ブロック・コード単独再生、音編集メニューは削除していません。音符が未選択の場合はクイック再生ボタンを無効化します。

## v0.7.4
クイック再生は▶のみ29×29px。停止は従来の再生操作から利用。ピアノロールに重ならない通常配置に変更。

## v0.7.5 録音の高度な読み取り設定
音声譜面化の高度設定を折りたたみメニューとして追加：音量検出感度、音程判定の厳しさ、揺れ補正、読み取り音域、標準設定へのリセット。既存の譜面化設定とv0.7.4までの編集・再生操作は維持。これらの設定は単音の音声譜面化にのみ適用され、録音ファイルの音質補正や複数楽器の分離はしません。
