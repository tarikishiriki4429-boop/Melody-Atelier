# Melody Atelier v0.5.0 — 歌詞からメロディーとコードへ

iPad Safari向け・無料・端末内編集のWebアプリ。GitHub Pagesに設置でき、Netlifyは不要です。コード進行140案・メロディー128案・自作コードライブラリを含みます。

## v0.5.0 の画面と長時間作曲対応

- **上下レイアウト**：歌詞・Aメロなどの構成を上段、メロディー編集グラフを下段にフル幅表示。グラフはメロディー・コードテンプレートより前に置き、すぐ操作できます。
- **音域 C2〜C8（MIDI 36〜108、73半音）**：縦スクロールで移動でき、「↑ 1オクターブ高く」「↓ 1オクターブ低く」「選択音へ」ボタンを追加。
- **横スクロール＋ズーム**：各ブロックの音符開始位置は最大4096拍。ズーム25〜300％。長い曲でもグラフ全体を巨大な画像として確保せず、表示されている範囲だけ描画してiPadのメモリを節約します。
- **8分の楽曲を検証**：BPM120で40小節×6ブロック＝8分（960拍）の作例から、8分WAVファイルの生成をブラウザーテストで確認。歌詞・コード・音符の密度が増えると端末への負荷も増えます。
- **ガイドWAVは最大15分**（元々の上限を継続）。ただしVoice Atelier v0.3.1との連携では**1ブロック48小節以内、40ブロック以内**にする必要があります。長い曲はAメロ・サビ・間奏などに分割してください。
- **保存形式は変更なし**。以前のMelody Atelierの編集用JSONプロジェクトを引き続き読み込めます。ただし更新前にJSONをバックアップしてください。

## Voice Atelierとの連携


1. Melody Atelierで歌詞、Aメロ/Bメロ/サビのブロック、メロディーを作ります。
2. 必要ならコード伴奏のON/OFFを切り替えます。
3. **「↗ Voice Atelierへ渡すZIP」** を押し、`…-Voice連携.zip` をiPadの「ファイル」に保存します。
4. Voice Atelier Song Studio **v0.3.1以降**の **「↗ Melody連携ZIPを取り込む」** を使います。
5. 歌詞・ブロック順・配置開始拍・BPM・拍子・合成したメロディーガイド音声がVoiceに入ります。別の声レイヤーに録音できます。

ZIPには `bridge.json`、`guide.wav`、`melody-project.json` が含まれます。 `melody-project.json` はMelody Atelierで引き続きメロディーやコードを編集するための情報です。Voice側のメロディーガイドはWAV音声なので、**Voice内で1音ずつの音程編集はできません**。ガイドは最大15分。1ファイルとして書き出します。長時間の作成はiPadのメモリや処理性能に依存します。

**Voice側で連携ZIPを読み込むと現在の歌詞・ブロック・録音・編集は置き換わります。既存の曲を必ず先にVoice側で「プロジェクト一式ZIP」にバックアップしてください。**

## 他の編集機能

- 歌詞の読みをモーラ単位に分解し、画面の音符をドラッグして音程・タイミング・長さを編集。
- Aメロ、Bメロ、サビなどのブロックを複製・並べ替え・個別転調。
- 16カテゴリー×8案=128種類のメロディー出発点。
- 14カテゴリー×10案=140種類のコード進行。試聴・編集・自作進行の保存・再利用。
- 選択したメロディー範囲から3種類のコード案を生成。選択範囲への採用／編集欄へコピー。
- 伴奏つきガイドの再生・WAV出力（最大15分）・MIDI書き出し。
- プロジェクトは **JSON** で保存・再編集。**連携用ZIPと編集用JSONは別物** です。JSONも必ずバックアップしてください。

## インストール

このフォルダーの `index.html`, `app.js`, `chords.js`, `styles.css`, `icon.svg`, `manifest.webmanifest`, `sw.js` をGitHub Pagesの公開リポジトリの直下に配置。Pages設定で main / (root) を選択し、SafariでHTTPSページを開き「ホーム画面に追加」。リポジトリにはアプリのコードが公開されますが、歌詞や作成データは自動公開しません。ユーザーの操作によってZIPを明示的に保存します。iPad Safariの長時間処理やオフライン動作は端末実機で未検証です。
