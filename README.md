# Melody Atelier v0.5.8

## 今回追加：参考音声ミニプレーヤー

- 画面右下の「🎧 参考音声」を押すと小さな音声プレーヤーが開きます。不要なときは折りたためます。
- iPadのファイルから音声を選択。再生／一時停止／シークバー／音量／再生速度（0.75・1・1.25倍）。
- 読み込める形式はSafariがデコードできる音声（一般的なM4A／MP3／WAVなど）。形式によっては再生できません。
- ファイルはブラウザー内の一時URLとして参照し、サーバーにアップロードしません。アプリの曲データ、WAV、Voice Atelier連携ZIPへ自動混入しません。
- **再読み込み・アプリ終了後には、音声ファイルを再選択してください。** 歌詞・メロディーの保存とは別扱いです。
- 再生音声とアプリのメロディーの位置は**自動同期しません**。録音を参考として耳で比較するための独立再生機能です。
- 長時間ファイルは全体をメモリに読み込まず、Blob URLを通してブラウザーで再生します。
- iPadでHTML音声の個別音量指定が効かない場合は、本体の音量操作で調整してください。

# Melody Atelier v0.5.7

v0.5.6の機能を維持し、次を追加：

- 音階表示の切り替え（C・D・E / ド・レ・ミ〔固定ド〕）。グラフ左側、中央ド、音程選択、選択音情報、調の表示へ即時反映。
- 表示切り替えだけなので、音程・保存済みメロディー・試聴音・MIDI・コードの鳴り方は変更なし。
- 表示の好みをローカル自動保存とプロジェクトJSONに保存。旧プロジェクトは従来のC・D・E表記で読み込み。

以前のv0.5.6で追加されている機能：

- 音符の配置・ドラッグ・微調整を1/4、1/8、1/16拍から選択（既定1/8拍）。半音刻みを維持。
- 「▧ 範囲選択」で矩形を描き複数音を選択、一括ドラッグ／上下左右微調整／まとめて削除。
- コード進行を計178種類に拡張。速い進行、ゆっくり、激情、透明感、半音上昇・下降。
- コードの長さに1/4・3/4・1.5拍を追加。ルートの半音調整（♭、♯）を追加。
- コードの鳴らし方を8種類から選択（1/4拍で刻む・半拍で刻む・分散和音など）。WAV、コード試聴、Voice連携に反映。
- 従来のプロジェクトJSON・自作コードライブラリ形式と互換。

**重要**: 新機能の操作をiPad Safari実機では未確認です。更新前にはプロジェクトJSONとコードライブラリを必ず書き出してください。GitHub Pagesにアップロードする際はZIPを解凍し、中身のファイルを配置します。
